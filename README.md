# Proiect Web React

Un proiect web creat cu React și Vite pentru gestionarea utilizatorilor, notițelor și proiectelor.

## Tehnologii folosite

- React
- Express
- MongoDB

## Instalare și pornire

1. Instalează dependențele:
   ```bash
   npm install
   ```
2. Pornește serverul de dezvoltare React:
   ```bash
   npm run dev
   ```
3. Pornește serverul backend:
   ```bash
   node server/index.js
   ```
